### 🏢 Property Hub

A full-stack property management platform designed to manage properties, buildings, units, tenants, leases, payments, maintenance requests, and notifications.

**Key features:**

* 🔐 JWT authentication and role-based authorization
* 🏠 Property, building, and unit management
* 👥 Tenant and lease management
* 💰 Rent and payment management
* 💳 Chapa payment integration
* 🔔 Real-time-style notification workflows
* 🛠️ Maintenance request management
* 📊 Role-specific dashboards and reports
* 🗄️ ASP.NET Core Web API with SQL Server
* ⚛️ React + TypeScript frontend

**Tech:** `ASP.NET Core` `C#` `Entity Framework Core` `SQL Server` `React` `TypeScript` `MUI`
